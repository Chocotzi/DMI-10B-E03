# Rúbrica — Semana 1: diagnóstico reproducible

La actividad vale 8 puntos. El quiz individual se califica por separado y vale 3 puntos.

| Criterio | Evidencia para obtener el puntaje completo | Puntos |
|---|---|---:|
| Reproducción | La versión identificada por el SHA se instala y todas las comprobaciones obligatorias pasan. | 2.5 |
| Definición del caso | Se explican alcance, actores, flujo, tres riesgos priorizados y criterios de aceptación verificables. | 2.0 |
| Diagnóstico de falla | Se conserva evidencia del fallo y de la corrección; se distingue síntoma de causa y no se alteran las pruebas. | 1.5 |
| Decisión técnica | La decisión compara al menos dos alternativas, explica beneficio y costo, y se conecta con una comprobación real. | 1.5 |
| Evidencia individual | Los tres integrantes identifican una contribución, sus commits/archivos y una prueba o revisión que pueden explicar. | 0.5 |
| **Total** |  | **8.0** |

## Condiciones importantes

- Sin SHA válido o sin reproducción, la parte automática vale 0 y el máximo es 4.8/8.
- Si se modifica, desactiva o ignora una prueba para ocultar una falla, no se acredita el diagnóstico.
- Un secreto o dato personal real expuesto limita la actividad a 4.8/8 y la credencial debe revocarse.
- Sin evidencia individual, ese criterio vale 0.
- Una captura puede complementar la evidencia, pero no sustituye comandos, reportes y archivos reproducibles.
- Una señal que requiera aclaración no implica por sí misma una penalización.
